# kaggle-competitions
ML/DL Kaggle Competition Submissions


A few machine learning assignments I've worked on while learning ML through IIT Madras and Kaggle.

## 1. Flight Price Prediction
**Notebook:** [`flight-price-prediction.ipynb`](notebooks/flight-price-prediction.ipynb)

Predicting flight ticket prices using the given features.

- **R² score:** 0.971    (on test data)

## 2. Bank Customer Churn
**Notebook:** [`bank-customer-churn-prediction.ipynb`](notebooks/bank-customer-churn-prediction.ipynb)

Predicting whether a bank customer is likely to leave.

- **F1-score:** 0.6628    (on test data)

## 3. Mushroom Classification
**Notebook:** [`mushroom-edibility-classification.ipynb`](notebooks/mushroom-edibility-classification.ipynb)

Classifying mushrooms as edible or poisonous based on their features.

- **Test accuracy:** 98.9%    (on test data)
